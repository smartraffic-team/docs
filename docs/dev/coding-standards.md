# Padrões de Código

## Diretrizes

- mudanças pequenas e testáveis;
- sem segredos em código/versionamento;
- não inferir dados não medidos;
- manter contratos de API estáveis.

## Python

- separar captura/detecção/controle;
- evitar bloquear loop principal com I/O externo.

## API

- validação de DTO;
- autenticação/autorização no servidor.
