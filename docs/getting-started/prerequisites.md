# Pré-requisitos

- Windows com Docker Desktop ativo
- Node.js 24 LTS + npm
- Python 3.10+
- Git

Validação rápida:

```powershell
docker --version
docker compose version
node -v
npm -v
python --version
```

> Se `dockerDesktopLinuxEngine` não existir, abra o Docker Desktop e aguarde ficar `Running`.
